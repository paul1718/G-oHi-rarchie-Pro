🚀 Comment lancer l'application localement

Lancer le serveur de développement :

bash
npm run dev

Ouvrez votre navigateur sur : http://localhost:3000

(Optionnel) Pour connecter une base Supabase distante :

Exécutez le script schema.sql dans le SQL Editor de Supabase.
Créez un fichier .env.local à la racine :
env
NEXT_PUBLIC_SUPABASE_URL=https://votre-projet.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=votre_cle_anon_publique

Le build de production Next.js a été compilé avec succès et la totalité des fichiers a été versionnée dans le dépôt Git local (main).
