GéoHiérarchie Pro - Guide de démarrage rapide

1. Lancement en un clic :
Double-cliquez sur le fichier "lancer-application.bat" dans ce dossier.

2. Lancement depuis PowerShell :
Ouvrez PowerShell dans ce dossier et tapez :
npm run dev

3. Accès à l'application :
Ouvrez votre navigateur sur : http://localhost:3000

4. Fonctionnalités :
- Exploration et gestion de la hiérarchie : Continent > Pays > Ville > Quartier > Code Postal
- Base de données locale autonome avec persistance automatique
- Téléchargement direct du tableau sous format Excel (.xlsx) et CSV
- Filtres en cascade et recherche en temps réel
- Formulaire d'ajout, modification et suppression (CRUD complet)
