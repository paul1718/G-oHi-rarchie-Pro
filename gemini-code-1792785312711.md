Tu es un développeur Web Full-Stack Senior expert en Next.js, Supabase et TailwindCSS. Ta mission est de créer une application web complète qui affiche et gère une hiérarchie géographique (Continent > Pays > Ville > Quartier / Arrondissement > Code Postal).

### 🎯 Objectif de l'application
Développer une interface dynamique avec un tableau récapitulatif permettant d'explorer, filtrer, rechercher et ajouter/modifier des localisations géographiques structurées.

### 🗄️ Architecture & Base de Données (Supabase / SQL)
1. Conçois un schéma de base de données relationnelle propre ou une table principale optimisée contenant les champs suivants :
   - `id` (UUID ou Integer)
   - `continent` (String)
   - `pays` (String)
   - `ville` (String)
   - `quartier_arrondissement` (String)
   - `code_postal` (String)
   - `created_at` (Timestamp)

2. Génère un script SQL d'initialisation (`schema.sql`) incluant :
   - La création de la table.
   - L'insertion d'un jeu de données de test varié (ex: Europe/France/Paris, Afrique/Cameroun/Douala, Amérique/Canada/Montréal, etc.).

### 💻 Interface Utilisateur (Frontend - Next.js + TailwindCSS)
Crée une interface moderne, propre et responsive comprenant :

1. **Tableau Interactif** :
   - Colonnes : Continent | Pays | Ville | Quartier / Arrondissement | Code Postal | Actions.
   - Pagination et tri par colonne (ordre alphabétique).
   - Design épuré avec TailwindCSS (mode clair/sombre optionnel).

2. **Filtres et Recherche** :
   - Barre de recherche globale (recherche en temps réel).
   - Filtres en cascade (ex: sélectionner un Continent pour restreindre la liste des Pays, puis des Villes).

3. **Formulaire de Gestion (CRUD)** :
   - Un formulaire (modal ou section dédiée) pour ajouter une nouvelle entrée.
   - Option de modification et de suppression directement depuis le tableau.

4. **Exportation de Données** :
   - Un bouton d'exportation du tableau au format CSV ou JSON.

### 🛠️ Spécifications Techniques
- **Framework** : Next.js (App Router) + TypeScript.
- **Styling** : TailwindCSS + composants Lucide React pour les icônes.
- **Gestion d'état / Données** : Server Components + Client Components optimisés pour une mise à jour fluide.
